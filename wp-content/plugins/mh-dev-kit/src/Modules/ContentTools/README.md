# Content Tools Module

Content authoring blocks, shortcodes, and structured landing pages.

## Features

| Feature | Description |
|---------|-------------|
| Children Pages | Gutenberg block + `[mhdk_children_pages]` shortcode |
| Markdown Editor | Dynamic Gutenberg block (marked.js CDN) |
| Local Ad Page | Suburb landing pages + REST API for AI agents |

## Admin hub

**MHDK Settings → Content Tools** (`mhdk-content-tools`)

## Enable module

**MHDK Settings → Modules** — enable **Content Tools**.

See each feature README under `Features/{Feature}/README.md`.
