# Site Tools Module

Site-wide admin utilities and frontend calculators.

## Features

| Feature | Description |
|---------|-------------|
| Backend Restrict Origin | Referer/Origin guard for wp-admin with settings toggle |
| Map Distance | `[mhdk_map_distance]` shortcode with haversine geolocation |

## Admin settings

| Page | Slug |
|------|------|
| Backend Restrict Origin | `mhdk-settings-restrict-origin` |
| Map Distance Settings | `mhdk-settings-map-distance` |

## Enable module

**MHDK Settings → Modules** — enable **Site Tools**.

See each feature README under `Features/{Feature}/README.md`.
