# User Tools Module

Per-user utilities: QR codes, vCards, link pages, and family trees.

## Features

| Feature | CPT | Public access |
|---------|-----|---------------|
| QR Code | `mhdk_qr_code` | Shortcode (author/admin) |
| vCard | `mhdk_vcard` | Shortcode + `/vcard/{id}/` download |
| Shortlinks | `mhdk_link_page` | `/l/{slug}/` |
| Family Tree | `mhdk_family_tree` | Shortcode + REST save |

## Admin hub

**MHDK Settings → User Tools** (`mhdk-user-tools`)

## Enable module

**MHDK Settings → Modules** — enable **User Tools**.

See each feature README under `Features/{Feature}/README.md`.
